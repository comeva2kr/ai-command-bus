용도: 클로드 디자인 세션에 앱 전체 디자인 설계를 맡길 때 아래 "프롬프트 본문"을

## 프롬프트 본문 (여기부터 끝까지 복사)

당신은 20년차 프로덕트 디자이너다. 아래 블루프린트의 서비스 "지금핫"의 전체
디자인 시스템을 설계하라. 결과물이 "AI가 만든 티"가 나면 실패다.

### 작업 순서 (건너뛰기 금지)
1. **브레인스토밍**: 이 서비스의 성격(한국 커뮤니티+뉴스 화제글 큐레이션)에서
   출발해 디자인 컨셉 3문장을 먼저 쓴다. 무드 레퍼런스는 실존 사례로
   (예: 당근의 친근함, 토스의 명료함, 뉴닉의 편집감 — 단 모방이 아니라 좌표).
2. **토큰 시스템 확정**: 색 4~6개(네임드 헥스), 서체 역할 2개(디스플레이/본문
   — 시스템 폰트 스택 기반, 웹폰트는 셀프호스트 가능한 것 1개까지 허용),
   radius 1값, spacing 스케일, 그림자 정책. **시그니처 요소 딱 1개**를 정한다.
3. **자기 비평**: "이 결과가 브리프와 무관하게 아무 앱에나 나올 디폴트 룩인가?"
   를 자문하고, 그렇다면 2로 돌아간다.
4. **구현**: 화면별 목업을 단일 HTML(인라인 CSS, 외부 의존성 없음)로 만든다.

### 네거티브 제약 (하나라도 어기면 재작업)
- 보라/인디고 그라데이션, 글로우 박스섀도, glassmorphism 금지
- 이모지를 아이콘 대용으로 쓰지 말 것 — 24px 그리드 전용 SVG 아이콘 세트 설계
- 전체 대문자 헤드라인, 장식용 01/02/03 마커 금지
- "크림+세리프+테라코타", "거의검정+비비드 단색 악센트", "무테두리 신문형"이
  기본값처럼 나오면 재검토 (의도가 있다면 그 의도를 명시)
- Inter류 기본 폰트 무성찰 사용 금지, radius 8px 방치 금지
- 애니메이션 산발 금지 — 시그니처 모먼트 1곳에만

### 필수 산출물
1. `DESIGN.md` — 토큰 전체(코드에 그대로 옮길 CSS 변수 블록 포함), 컨셉 서술,
   아이콘 세트 스펙(스트로크 굵기·코너·그리드), 컴포넌트 규칙
2. 화면 목업 HTML: ①홈 피드 ②글 상세(바텀시트) ③브리핑 페이지 ④랭킹
   ⑤온보딩 설문 — 모바일 390px 기준, 다크/라이트 둘 다
3. 아이콘 세트 SVG: 핫, 최신, 브리핑, 랭킹, 트렌드, 댓글, 공유, 좋아요,
   별로예요, 스크랩, 메뉴, 닫기, 원문가기, 검색 (14종)
4. 마이크로카피 가이드: 빈 상태·에러·버튼 라벨 원칙 (행동 언어)

### 블루프린트

**서비스**: 지금핫 NowHot (nowhot.kr) — 한국 커뮤니티(보배·뽐뿌·클리앙·인벤·
더쿠·이토랜드 등)와 뉴스의 "지금 화제인 글"만 모아주는 모바일 웹앱(PWA).
운영: 페퍼클럽. 수익: 광고(애드센스·애드핏)+제휴(쿠팡). 사용자: 출퇴근에
10분씩 보는 20~40대 한국인 + 커뮤니티 헤비유저.

**톤**: 시끄러운 인터넷을 대신 읽어주는 "정리 잘하는 친구". 선정적이지 않고,
근거 수치를 보여주는 정직함이 브랜드다. 이름처럼 "지금·뜨거움"의 긴장감은
필요하지만 도배식 빨강은 금지.

**화면 인벤토리** (전부 목업 대상 아님 — 필수 5개는 위 산출물 참조):
- 홈 피드: 상단 브랜드 헤더 → "지금 브리핑" 가로 카드 스트립(카테고리별 대표
  이슈+X트렌드 카드) → 정렬 탭(핫/최신) → 카테고리 칩 → 무한 피드 카드
- 피드 카드: 소스 컬러도트+소스명+카테고리, 제목(2줄), 썸네일(핫링크라 로드
  실패 잦음 — 실패 시 우아한 플레이스홀더 필수), 근거 배지(▲추천·댓글·
  N개 매체 교차보도), 새탭 원문 지름길
- 광고 카드: 유기 카드와 같은 레이아웃 + "AD" 배지(탭하면 고지 전문 팝오버)
  — 법적 고지 요건이라 배지 삭제 불가
- 글 상세: 바텀시트(모바일)/중앙 카드(데스크톱). 제목(탭=원문), 썸네일, 발췌
  (≤200자, 저작권 제약 — "원문에서 계속 읽기" CTA가 핵심 동선), 좋아요/별로,
  원문 댓글수와 지금핫 댓글 분리 표시, 댓글 작성
- 게시판(소스) 보기: 특정 커뮤니티의 베스트 전체 목록
- 브리핑: 서버 렌더 편집 페이지(카테고리 섹션·근거 수치 문장), 날짜 아카이브
- 랭킹: 일/주/월 TOP 20, 항목마다 근거 수치
- X 트렌드: 키워드 TOP 20 리스트(외부 링크)
- 드로어: 취향 정확도 미터, 카테고리·소스 필터, 뉴스 성향 슬라이더(진보~보수),
  19금 토글(성인인증 후), 정치/종교 토글, 로그인(카카오·네이버·구글)
- 온보딩: 첫 방문 환영 모달 + 취향 설문(카테고리·태그·커뮤니티 선택)

**하드 제약 (디자인이 못 바꾸는 것)**:
- 콘텐츠는 발췌+아웃링크 구조 (저작권) — 본문 전문 표시 불가
- 이미지는 원본 서버 핫링크만 — 실패율 높음, 플레이스홀더 시스템 필수
- 광고 고지(AD 배지+접근 가능한 고지 전문), 쿠팡 대가성 문구는 법정 요소
- 19금/정치/종교는 기본 숨김 게이트 존재
- 구현은 단일 index.html + 인라인 CSS(제로 의존성 Node 서버) — 빌드 도구 없음,
  CSS 변수 기반이어야 이식 가능
- PWA: 설치 배너·오프라인 셸 존재, prefers-reduced-motion 존중, 대비 WCAG AA
- 기존 기능 제거 금지 — 스타일 재설계이지 기능 재설계가 아님

**현행 자산 (참고·계승 여부는 디자이너 판단)**:
- 브랜드 마크: 화제성 급상승 스파이크(차콜 바탕, 흰 흐름선→코랄 급등선+피크
  도트), 시그니처 코랄 #FF4B3E
- 현행 다크 토큰: 바탕 #0e0f13 · 카드 #171922 · 텍스트 #e8eaf0 · 액센트
  #4f8cff · 라인 #262a38
- 검토된 방향 3종: A 다크 에디토리얼 / B 라이트 페이퍼(신문식 순번) / C 코랄
  블록 볼드 — 이를 넘어서는 제4안도 환영하되 근거를 쓸 것

(프롬프트 끝)
