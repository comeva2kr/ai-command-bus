## 2. 독립성 규칙

1. 각 좌석은 위 다섯 파일만 공통 입력으로 읽고 다른 좌석의 결과를 읽지 않는다.
2. 먼저 실패 가설과 반증 조건을 작성한 뒤 장점을 기록한다.
3. 제품이 아직 구현되지 않았다는 사실을 전제로 설계 주장과 런타임 증거를 구분한다.
4. 근거 없는 업계 관행이나 회사 내부 사정을 실제 사실처럼 쓰지 않는다.
5. 공개 자료를 사용한 경우 URL과 확인일을 남기고, 추론은 추론이라고 표시한다.
6. 결론은 `PASS`, `PASS_WITH_LIMITATION`, `HOLD`, `BLOCKED` 중 하나로 제한한다.
7. 공식 자료와 공통 스냅샷은 한 번 만든 패킷을 재사용하고 같은 조사를 반복하지 않는다.
8. 통합자는 중복 발견을 한 번만 설명하고 독립 동의 좌석 수만 보존한다.

## 2.2 실제 실행 영수증과 비용 지시 반영

- 비용 절약 지시 전에 R1~R6 여섯 독립 좌석이 이미 시작됐다.
- 비용 절약 지시 뒤 새 독립 좌석을 연 수: `0`
- R7 디자인은 이미 문맥을 읽은 R5 좌석에 한 번의 제한된 보충 검수로 요청했다.
- 최종 증거 수: `독립 결과 6개 + 비독립 보충 렌즈 1개`
- 공식 공개 자료는 통합자가 한 번 조사한 패킷을 재사용했다.
- 결과 수집 뒤 모든 검수 좌석을 종료했다.

따라서 R7은 독립 동의 수와 평균 점수에 포함하지 않는다. 위 세 그룹은 실행 수를
뜻하지 않고 통합 보고서의 편집 구조로만 사용한다.

## 5. 좌석별 공격 관점

### R1. Techmeme 편집·클러스터링 좌석

- 사건 클러스터 정확도, 원출처와 선도 보도 식별, 중복 제거를 공격한다.
- 속도와 편집 판단의 균형, 홈에서 중요도 위계가 즉시 보이는지 검수한다.
- 광범위한 카테고리가 기술 뉴스 수준의 신호 밀도를 유지할 수 있는지 반증한다.

### R2. Ground News 관점·출처 투명성 좌석

- 독립 출처 수와 실질 소유 다양성을 혼동하는지 공격한다.
- 편향, 사각지대, 보도 차이, 원출처 신뢰를 사용자에게 어떻게 설명할지 검수한다.
- 신뢰 점수가 하나의 권위 숫자로 오해될 위험을 반증한다.

### R3. Particle AI 뉴스 제품 좌석

- LLM 요약의 근거 연결, 중복 사건 결합, 개인화와 인터랙티브 탐색을 공격한다.
- 공용 편집 재고만으로 개인 효용이 충분한지, 사용자별 재생성 금지가 과도한지 검수한다.
- 모델 비용·지연·환각·일관성 실패를 실제 제품 흐름에 대입한다.

### R4. 뉴닉 한국어 브리핑·습관 좌석

- 한국 사용자가 하루 세 번 다시 올 이유, 문체, 설명 깊이, 피로도를 공격한다.
- 다양한 카테고리를 한 목소리와 한 화면에서 다룰 때 정체성이 흐려지는지 검수한다.
- 정보량이 늘어날수록 완독·신뢰·생활 효용이 같이 커지는지 반증한다.

### R5. 네이버 개발 좌석

- 수집, 시계열 신호, 클러스터, LLM, 검증, 캐시의 장애 전파를 공격한다.
- 지연 예산, 재처리, 관측 가능성, 데이터 계보, 비용 상한, 롤백을 검수한다.
- 소규모 팀이 포털급 범위를 운영할 수 있다는 가정을 반증한다.

### R6. 네이버 기획 좌석

- 핵심 사용자, 첫 주 가치, 콜드스타트, 리텐션, 공급 부족을 공격한다.
- 카테고리 수와 콘텐츠 양의 단순 비례가 실제 효용으로 이어지는지 검수한다.
- 수익화가 신뢰와 재방문을 해치지 않는 측정 계약이 있는지 반증한다.

### R7. 네이버 디자인 좌석

- 첫 화면 정보 위계, 모바일 밀도, 복귀, 판본 전환, 출처 설명을 공격한다.
- 긴 연속 페이지가 선택지가 많은 사용자를 압도하는지 검수한다.
- 접근성, 스캔성, 상태 표시, 오류·빈 상태가 설계됐는지 반증한다.

## 6. 통합 판정 규칙

- 한 좌석이라도 근거 있는 `P0`를 제시하면 전체 판정은 자동 `PASS`가 될 수 없다.
- 같은 문제가 3개 이상 좌석에서 독립적으로 나오면 공통 구조 결함 후보로 올린다.
- 좌석 간 충돌은 다수결로 지우지 않고 결정 실험과 소유자를 지정한다.
- 문서·테스트 통과는 구현·런타임·사용자 가치·수익성 증거로 승격하지 않는다.
- 최종 보고서는 사실, 각 좌석의 판단, 통합 추론, 미확인을 분리한다.
