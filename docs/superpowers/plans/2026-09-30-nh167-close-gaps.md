## 변경 전 보안 검토
공개 수집 자료/URL/검수 파일은 외부 입력이며 해시·원제목·슬롯 결합을 유지한다. 빌더는 기존 spawn 인자 경로를 재사용한다. 캠페인 입력은 기존 정규화와 봇 제외를 재사용하며 admin 인증을 보존한다. 정확 구간 기록은 익명 내부 식별자를 제한 기간 보관하고 API는 합계만 제공한다. 운영 접근은 공개 편집 파일만 읽고 환경변수·feed.json 사용자 자료를 외부로 꺼내지 않는다.

## 3자 반박으로 확정한 가변 분량 경계
- 14개 분야가 모두 14개씩 채워지면 기존 196개 한도에는 추가 기사가 들어갈 수 없다. 공유 잔여 예산으로 앞 분야부터 잘라 넣는 안은 분야별 독립 목록·정확 합집합을 훼손하므로 채택하지 않는다.
- 새 가변 판본은 분야별 최대 20개, 합집합 최대 280개로 일치시킨다. 기존 판본 읽기는 보존한다. 15번째 이후에는 실제 당해 슬롯의 뉴스·복수 출처 근거가 있어야 하며 인기 점수나 가짜 인간 검수 표시로 대체하지 않는다. 이 경로는 자동 다출처 뉴스 선별이지 인간 편집 검수라고 부르지 않는다.
- 공급이 부족하면 8개를 맞추기 위해 오래된 글을 넣지 않는다. 부족분·부분 제공 상태를 유지한다. 20개 한도는 유료 호출 예산과 별개이며 이번 작업은 유료 기사 생성 호출 없이 검증한다.
