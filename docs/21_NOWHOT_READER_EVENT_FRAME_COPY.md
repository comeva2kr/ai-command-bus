## 불변 패킷 승계

독자 문안이 같더라도 품질 계약, reader 계약, 문안 payload, reader 기계 판정이
달라지면 새 패킷 ID를 만든다. 사람 입력이 0인 같은 저장 판만 새 계약으로
승계하며 기존 패킷은 대기열에서 지우지 않는다. 완료 행이 0이어도 메모, 일부
체크, 빈 검수 초안, 조정 원장이 한 번 저장되면 사람 작업으로 보고 교체하지
않는다. 회귀 테스트는 구형 패킷 보존과 같은 판의 v3 패킷 승계를 직접 검증한다.
