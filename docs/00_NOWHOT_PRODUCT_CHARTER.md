## 한 문장 사명

> 지금핫은 사용자가 선택한 관심 카테고리의 국내외 뉴스·정보·유머·지식을
> 신뢰할 수 있는 공개 근거와 실제 확산 신호로 선별하고, 아침·낮·저녁 하루 세
> 번 완결된 개인 브리핑으로 제공해 여러 곳을 찾아다니지 않고도 중요한 변화를
> 놓치지 않게 하는 서비스다.

## 사용자에게 하는 말

> 찾아다니지 마. 여기 있어. 내 관심사에서 지금 알아야 할 것만, 하루 세 번.

## 핵심 사용자

- 주식·부동산·테크·유머·유행·지식 등 자신이 선택한 분야를 한곳에서 따라가고
  싶은 한국어 사용자
- 국내외 뉴스·커뮤니티·공식 자료를 매번 직접 찾아다닐 시간이 없는 사용자
- 단순 인기 순위보다 `무슨 일인지`, `왜 중요한지`, `왜 지금 뜨는지`, `무엇이
  달라졌는지`를 빠르게 알고 싶은 사용자
- 아침·낮·저녁 세 번의 확인만으로 선택한 분야의 중요한 흐름을 놓치지 않으려는
  사용자

연령·직업·정치 성향을 임의로 좁히지 않는다. 실제 이용 데이터가 쌓이기 전에는
가상의 세부 페르소나를 사실처럼 사용하지 않는다.

## 카테고리 플랫폼 경계

지금핫은 경제 전문 서비스가 아니다. 경제·정치·주식, 부동산, 테크·AI,
사회·세계, 문화·연예, 스포츠, 유머·밈·유행, 지식·과학, 생활·건강,
게임·취미 등 사용자가 선택할 수 있는 관심사를 확장 가능한 카테고리 정책 팩으로
다룬다. 이 목록은 최종 상한이 아니다.

공통 엔진은 수집, 확산 신호, 중복 제거, 사건 클러스터, 다축 선별, LLM 편집,
검증, 하루 세 판만 책임진다. 분야마다 다른 양질 출처, 핫 신호, 중요도 기준,
검증 조건과 편집 형식은 카테고리 정책 팩이 책임진다. 시장·정책은 이 구조를 먼저
검증하는 파일럿일 뿐 제품 정체성, 홈 기본값 또는 전체 카테고리의 품질 증명이 아니다.

## 사용자 약속

1. 명시적으로 선택한 카테고리가 일반 브리핑 지면의 주인이 된다.
2. 한 카테고리를 고르면 그 분야를 깊게, 여러 카테고리를 고르면 유효한 내용과
   페이지 길이를 충분히 늘려 제공한다.
3. 국내외를 가리지 않고 신뢰할 수 있는 출처와 실제 확산 근거를 함께 보여준다.
4. 아침·낮·저녁 하루 세 판으로 새 사건과 이전 판 이후의 변화를 제공한다.
5. 고정된 `상위 5개`나 큰 카드 몇 개로 끝내지 않고 한 연속 페이지에서 판본을
   완결한다.
6. 제목만 모으지 않고 `무슨 일`, `왜 중요한가`, `왜 뜨나`, `달라진 점`, `다음
   관전`을 제공한다.
7. 모든 핵심 설명은 공개 출처와 지금핫의 측정 근거로 되짚을 수 있다.
8. 측정된 사실, 지금핫의 해석, 아직 확인되지 않은 관전을 구분한다.
9. 행동 학습은 명시적 선택을 보조하며, 안 고른 분야를 조용히 추가하지 않는다.
10. 광고가 콘텐츠 선정이나 기본 이동을 지배하지 않는다.
11. 수집·LLM·검증 일부가 실패해도 마지막으로 검증된 판본은 계속 읽을 수 있다.

## 불변 제품 원칙

| ID | 원칙 | 판정 질문 |
|---|---|---|
| NH-P01 | 홈은 제품이다 | 첫 화면만 보고도 오늘의 브리핑 가치가 완결되는가 |
| NH-P02 | 하나의 서비스다 | 브리핑·실시간·상세·아카이브가 같은 셸과 이동 규칙을 쓰는가 |
| NH-P03 | 사건을 클러스터로 관리한다 | 같은 사건을 페이지마다 다시 만들거나 중복 노출하지 않는가 |
| NH-P04 | 근거가 해설보다 먼저다 | 모든 핵심 문장에 출처 또는 측정 근거가 있는가 |
| NH-P05 | 사실과 해석을 분리한다 | 측정값·확인 사실·해석·관전이 시각적으로 구분되는가 |
| NH-P06 | 오래 가는 수익을 택한다 | 단기 광고 노출이 신뢰·재방문·계정 안정성을 해치지 않는가 |
| NH-P07 | 장애 시에도 읽힌다 | 새 수집이 실패해도 마지막 검증본과 상태 시각이 제공되는가 |
| NH-P08 | 명시적 취향이 지면을 소유한다 | 선택한 카테고리가 자동 탐색·인기 편향보다 우선하는가 |
| NH-P09 | 하루 세 판은 변화 중심이다 | 같은 설명의 반복이 아니라 이전 판 이후 달라진 점을 주는가 |
| NH-P10 | LLM은 근거 안에서 편집한다 | 모델이 수치·출처 신뢰·사실을 추측하지 않고 주장별 근거를 남기는가 |

## 제품 순환

```text
수집 -> 시계열 반응·출처 측정 -> 사건 클러스터 -> 다축 선별
     -> LLM 의미 판정·구조화 편집 -> 주장·수치·출처 검수
     -> 하루 세 판의 검증 재고 -> 선택 카테고리별 페이지 조립
     -> 재방문·평가 신호 -> 편성·품질 개선 -> 문맥에 맞는 수익
```

수집량과 클릭 자체는 성공이 아니다. 선택 분야의 중요한 사건을 빠뜨리지 않고,
중복·과장 없이 이해 가능한 판본으로 제공하며, 이 흐름이 감당 가능한 LLM·인프라
비용으로 안정적으로 반복될 때 성공이다.

## 성공 기준

### 북극성 지표 후보

`주간 브리핑 충족 이용자`: 최근 7일 중 3일 이상 방문하고, 방문 시점의 최신 판에서
선택 카테고리의 핵심·변화 영역을 실제로 소비한 사용자 수.

현재는 정확한 읽기 이벤트 계약이 없으므로 `후보`다. 측정 구현과 데이터 품질 검증
전에는 숫자를 만들어 목표 달성으로 보고하지 않는다.

### 품질 보호 지표

- 선택 카테고리별 중대 사건 누락률과 유효 후보 포함률
- 독립 출처 충족률과 원출처·전재 구분률
- `무슨 일`, `왜 중요한가`, `왜 뜨나`, `달라진 점`의 근거 연결률
- LLM 문장의 미지원 주장률과 수정·철회율
- 중복 클러스터율, 오래된 정보 혼입률, 판본 간 무변화 반복률
- 중요 사건 탐지 지연과 마지막 성공 수집·편집·검증 시각
- 한 판에서 얻은 정보량 대비 소비 시간과 원문·상세 이동 후 복귀 성공률

### 사업 지표

- 재방문 사용자 1,000명당 순수익
- 광고가 없는 세션 대비 광고 세션의 이탈 변화
- 운영비, AI 비용, 인프라 비용을 뺀 기여이익

AdFit·AdSense 승인과 쿠팡 클릭 수는 중간 운영 지표다. 영구 제품 목표를 대신하지
않는다.

## 명시적 비목표

- 원문 제목을 많이 모으는 링크 디렉터리
- 클릭·댓글·체류시간만 최대화하는 추천 피드
- 속보를 가장 먼저 보도하는 언론사
- 근거 없는 정치 편향·신뢰 점수 서비스
- 선택하지 않은 카테고리를 발견 명목으로 자동 혼합하는 피드
- 사용자마다 전체 브리핑을 다시 생성하는 고비용 LLM 서비스
- 자동 생성 글을 대량 색인시키는 콘텐츠 공장
- 첫 화면을 가리는 광고·구독·설명용 랜딩 페이지
- 관리자나 편집자가 하루 종일 수동 편성해야만 유지되는 구조
