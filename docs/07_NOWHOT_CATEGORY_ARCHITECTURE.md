# NOWHOT-CATEGORY-ARCHITECTURE-001

- 상태: 로컬 검증 완료
- 환경: local only
- 변경 ID: `DEVCHG-NOWHOT-20260810-008`
- 목적: 범용 제품과 첫 시장·정책 검증 팩의 경계를 고정한다.

## 1. 제품 정체성

지금핫은 경제 전문 서비스가 아니다. 사용자가 선택한 수많은 관심사에서 지금 가장
중요하고 뜨겁고 유용한 내용을 국내외에서 골라 하루 세 번 제공하는 범용 개인
브리핑 플랫폼이다.

경제·정치·주식은 첫 검증 카테고리 팩이다. 현재 실험이 이 분야를 사용한다는 이유로
홈 기본값, 브랜드 설명, 범용 데이터 계약 또는 다른 카테고리의 선별 기준을 시장
중심으로 바꾸지 않는다.

## 2. 3층 구조

| 층 | 공통 책임 | 분야별 책임 |
|---|---|---|
| 범용 코어 | 수집, 신호 스냅샷, 중복 제거, 사건 클러스터, 다축 선별, LLM 편집, 검증, 판본 | 특정 시장·플랫폼·장르 규칙을 강제하지 않음 |
| 카테고리 정책 팩 | 공통 계약을 사용 | 양질 출처, 핫 신호, 중요도, 검증 트리거, 편집 형식, 제외선, 평가 fixture |
| 개인 브리핑 | 검증된 공용 재고 조립 | 사용자가 선택한 팩, 세부 취향과 유효 후보량에 따라 동적 분량 구성 |

## 3. 확장 가능한 카테고리 예시

- 경제·정치·주식
- 부동산
- 테크·AI
- 사회·세계
- 문화·연예
- 스포츠
- 유머·밈·유행
- 지식·과학
- 생활·건강
- 게임·취미

이 목록은 최종 분류표가 아니다. 새 분야는 카테고리 정책 팩 계약을 충족하면 기존
범용 코어를 복제하지 않고 추가할 수 있어야 한다.

## 4. 카테고리 정책 팩 계약

각 팩은 최소 다음을 선언한다.

1. `sourcePolicy`: 양질 출처, 소유·전재 관계, 허용된 접근 방식
2. `heatSignals`: 해당 분야에서 실제 확산을 나타내는 신호와 기준선
3. `importanceRules`: 놓치면 잃는 정보·판단·활용 가치
4. `verificationTriggers`: 공식 자료나 추가 교차 확인이 필요한 조건
5. `editorialTemplate`: 무슨 일, 왜 중요, 왜 뜨나, 왜 내게, 달라진 점의 분야별 표현
6. `exclusionRules`: 루머, 광고, 재업로드, 낚시, 전문성 과잉 등 제외 조건
7. `qualityFixtures`: 포함·제외·병합·분할·정정의 대표 평가 표본

## 5. 소스 원칙

기본 수집은 이용 조건을 확인한 양질의 보도·전문 자료·커뮤니티 신호를 분야에 맞게
조합한다. 모든 공식 원천을 상시 직접 해석하지 않는다. 중요 수치, 공시, 정책,
건강·안전, 출처 충돌처럼 오류 비용이 큰 주장만 공식 자료 또는 추가 독립 출처로
확인한다.

## 6. 첫 파일럿의 증명 범위

시장·정책 층화 평가 실험은 범용 코어의 클러스터, 계보, 근거 연결, 비용과 장애
내성을 검증하는 첫 사례다. 통과해도 다음을 증명하지 않는다.

- 지금핫이 경제 전문 서비스라는 것
- 시장·정책이 모든 사용자의 홈 기본값이라는 것
- 유머, 스포츠, 문화, 지식 등 다른 카테고리 정책이 준비됐다는 것
- 운영 배포나 실제 이용자 대상 품질이 승인됐다는 것

다른 카테고리는 공통 코어를 재사용하되 자체 정책 팩과 대표 fixture를 별도로 통과한다.
