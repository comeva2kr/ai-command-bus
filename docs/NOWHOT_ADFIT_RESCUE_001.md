# NOWHOT-ADFIT-RESCUE-001

## 목적

지금핫을 단순 외부 링크 모음이 아니라 자체 계측 데이터로 이슈를 해설하는 서비스로 전환하면서, 현재 사용자의 실시간 피드 경험은 유지한다.

## 변경 범위

- `/`: 자체 편집 홈. 오늘의 핵심 흐름, 데이터 리포트, 선정 방법을 서버 렌더링한다.
- `/live`: 기존 개인화 실시간 피드. 검색 색인과 디스플레이 광고에서 분리한다.
- `/briefing`, 발행된 `/briefing/YYYY-MM-DD`, `/report`: 심사·검색 대상 편집 지면.
- 랭킹·키워드·커뮤니티·트렌드·카테고리 페이지: 기능은 유지하되 `noindex,follow`, 사이트맵 제외, 디스플레이 광고 없음.
- AdFit 심사 모드: 편집 지면당 AdFit 최대 1개, AdSense·쿠팡 동시 노출 금지, `/live` 광고단위 전달 금지.

## 승인 조건

1. 전체 자동 테스트가 통과한다.
2. `/` 본문에 외부 링크 목록이 없고 자체 서술이 먼저 보인다.
3. `/live`는 기존 피드 기능을 유지하며 `noindex,follow`다.
4. 심사 모드의 `/`에는 AdFit 한 단위만 있고 AdSense·쿠팡이 없다.
5. 심사 모드의 `/live`에는 AdFit 광고단위와 광고 네트워크 로더가 없다.
6. 사이트맵은 `/`, `/briefing`, 발행 아카이브, `/report`, 필수 정책 페이지만 담는다.
7. 배포 전 롤백 기준 커밋과 검증 영수증을 남긴다.
