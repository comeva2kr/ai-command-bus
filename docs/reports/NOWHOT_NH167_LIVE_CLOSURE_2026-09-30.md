# NH167 오늘판 개선 — 최종 검수와 라이브 반영 기록

## 현재 상태
2026-09-30 23:05 KST 기준 **Codex·Fable·Grok 최종 검수 및 운영 이미지 검증 통과, 배포 진행**. 아직 이 문단을 라이브 완료로 해석하지 않는다. David의 “통과하면 라이브 시키고 알려줘” 승인으로 검수 통과한 정확한 후보를 배포한다.

## 이용자에게 달라지는 점
- 아침은 전날 19시 이후, 점심은 당일 7시 이후, 저녁은 12시 이후 새 소식을 우선한다. 이미 본 사건의 단순 재보도는 줄이고 실제 수치·확정 결과가 달라진 후속 소식은 남긴다.
- 같은 투싼 판매 발표가 세 카드로 반복되던 문제를 공통 사건 판정에서 고쳤다. `1천60만대`와 `1060만대`, `$99`와 `$99.00`를 같은 값으로 읽는다. 다른 차종·진짜 판매 증가·사상자 수 변경은 합치지 않는다.
- 경제 분야에 들어온 통일 여론조사·정치 고발·군 지뢰 사고·게임 시상식 등을 제외한다. 분류 근거가 있는 다른 분야는 유지하고, 근거가 없으면 억지로 옮기지 않는다. 코스피와 개별 종목을 엉뚱하게 묶어 복수 출처로 인정하던 문제도 수정했다.
- 분야별 14개 고정을 풀었다. 기본 최대14개, 해당 시간대에 독립된 보도 출처가 충분한 뉴스는 최대20개까지 제공한다. 8개를 목표로 하되 오래된 기사로 수를 채우지 않는다. 부족하면 부분 제공을 표시한다.
- 확인된 오역·제목과 발췌 교정은 목록과 상세에 함께 적용한다. 늦게 들어온 교정도 기사 선정과 순서를 다시 바꾸지 않고 반영하며, 같은 교정으로 재발행을 반복하지 않는다. 예전 공유 주소는 보존한다.
- 관리자에 게시 후 정확한 24·72시간 채널/게시물별 유입·읽기·원문 이동·광고 클릭·7일 뒤 재방문 분석을 추가했다. 브라우저 수를 사람 수로 부풀리지 않는다. 계측 전 구간은 0이 아닌 ‘미계측’이다.
- 이용자 업데이트 팝업과 소개의 업데이트 이력에 이번 오늘판 개선을 안내한다.

## 세 사람이 서로 반박해 닫은 문제
Codex가 통합·발행기·유입 계측·운영 검증을 담당했고, Orca Claude Fable 5.1 high가 편집 코드 수정, Cursor Grok 4.7 Extra High가 독립 반례 검수를 맡았다. 요청/실행 모델: Fable `claude-fable-5-1 high`(실행 영수증), Grok `grok-4.7-xhigh`(화면 관측, provider ACK는 미지원).

숫자만 같게 처리하는 안은 기각했다. 사망자 증가, 과거 판매 실적, 서로 다른 자동차 모델을 합치는 반례가 나와 원문 발췌의 ‘첫 판매 이정표’와 실제 주체가 맞을 때만 예외를 허용했다. 코스피와 개별 종목의 공통 단어만으로 출처를 묶는 것도 차단했다. Fable은 Codex의 교정 반복 오류를 발견했고, Codex 수정 뒤 Grok이 재검증했다. 단순 상호 동의로 통과시키지 않았다.

## 검증 결과
- 전체 **2,142/2,142 통과**, 실패0·건너뜀0. Node22, 실제 Chrome 브라우저 검사 포함.
- 발행 후 교정 경로 23/23 통과. 잘못된 교정은 한 번 보류, 정상 교정은 재선정·유료 호출 없이 반영, 다음 실행은 재반영 없음.
- 실제 수집 자료로 3개 판 재생. 유료 기사 생성 호출0. 날짜·시간대·정확한 판 ID·관심 분야 합집합·목록/상세/뒤로가기·원문 링크·가로 넘침·화면 오류를 확인했다.
- 운영과 같은 Linux Docker 이미지 빌드/구동 확인. 예전 판과 새 판 공유 API200, 관리자 비인증401, 과거 미계측 구간 `metrics:null` 확인.
- 복구 이미지도 실제 Linux에서 검증했다. 현재판 포인터만 복구해도 예전/새 공유 주소와 새 유입 기록이 유지된다. 운영 사용자 자료와 비밀값은 서버 밖으로 가져오지 않았다.
