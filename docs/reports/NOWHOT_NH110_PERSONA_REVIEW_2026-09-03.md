검수일: 2026-09-03 KST. 대상: 오늘의 NH107/NH108/NH109 로컬 변경과 David가 수용한 모닝/런치판. 체크포인트 `e25eacb` 이후 NH109는 미커밋 상태다. 이번 요청은 검수이며 수정/배포 승인이 아니다.

## 결론과 발견 사항

핵심 동작의 로컬 재검사는 통과했다. 수용한 기사 구성과 정본은 그대로다. 그러나 "결함 없음"은 아니다. 실제 이용자에게 보이는 아래 3건이 남아 있으며, 이번 검수에서는 고치지 않았다. 검사한 범위에서 사용을 막는 P1은 발견하지 못했다.

1. **P2: 경제 제목의 의미 오역.** ADP 원제의 `Private payrolls`를 "개인 급여", 고용 증가 38,000명을 "38,000건"으로 표시한다. 본문은 민간 기업의 고용 증가를 설명하므로 제목만 읽는 이용자가 다른 통계로 오해할 수 있다. 단순한 어색함이 아닌 의미/단위 오류다. [현재 응답](../../.nowhot-local/nh110/current-news-business.json), [보존된 원제](../../.nowhot-local/slot-editions/edition-2026-09-03-lunch-3613dacdf8c8.json:38664), [본문](../../.nowhot-local/slot-editions/edition-2026-09-03-lunch-3613dacdf8c8.json:38687).
2. **P2: ELLE 발췌에 사이트 안내문 혼입.** 디올 기사에 가입/로그인 안내와 "기사 제목 내용을 입력해주세요. 삭제하시겠습니까? 등록이 완료되었습니다."가 포함된다. 사진, 기사 내용, 원문 링크는 정상이다. 본문을 추출할 때 기사와 페이지 UI를 충분히 분리하지 못한 결과이며 정확한 발생 함수는 이번 검수에서 확정하지 않았다. [실제 화면](../../.nowhot-local/nh110/fashion-detail.png), [전체 표시문](../../.nowhot-local/nh110/fashion-date.json), [정본](../../.nowhot-local/slot-editions/edition-2026-09-03-lunch-3613dacdf8c8.json:34167).
3. **P2: 목록 출처 링크만 새 탭으로 열린다.** 상세창의 원문은 요청대로 같은 창이며 뒤로가기 복원도 통과했다. 하지만 목록의 파란 출처명에는 여전히 `target="_blank"`가 있다. 주 이용 경로의 장애는 아니지만 두 경로가 다르다. [원인 코드](../../src/feed/public/today.html:467), [실측 target 값](../../.nowhot-local/nh110/fashion-date.json). 상세 원문을 새 탭으로 되돌리는 것은 해결책이 아니다.

1, 2번은 보존된 수용판에도 있다. NH109 수정으로 새로 생겼다고 단정하지 않는다. 커뮤니티 원문 제한/본문 부족은 별도 P3 이용성 한계이며, 확인하지 못한 내용을 만들어 채우라는 뜻이 아니다.

## 실제 검수자와 방식

실제 모델 2개가 각 2명의 이용자 페르소나를 구성했다. 실제 고객 인터뷰가 아닌 시뮬레이션이다.

| 모델 | 페르소나 | 맡은 관점 |
| --- | --- | --- |
| Claude Sonnet 5, max effort, Claude Max | C1: PC 첫 방문 직장인 | 오늘 기본 진입, 뉴스/경제, 제목/출처/시간, 번역/원문 안내 |
| 같은 Claude 세션 | C2: 매일 읽는 모바일 이용자 | 커뮤니티 상세, 패션, 날짜/분야 변경, 읽을 내용의 충분함 |
| Cursor Grok 4.6 Extra High | G1: Android 알림 구독자 | 중복 알림, 상세/원문/뒤로가기, 오래된 링크 |
| 같은 Grok 세션 | G2: 복수 분야 헤비유저 | 고정 기사/출처, 합집합, 기사 구분, 번역/해외 언론 |

Orca의 별도 터미널에서 실제 Claude와 Cursor Grok을 실행했다. Codex가 기존 QA 도구로 현재 로컬판을 재실행하고 화면/JSON을 제공했다. 두 검수자는 그 증거와 직접 읽은 코드/로컬 응답을 각각 검토한 뒤 상대 의견과 추가 반례를 대조했다. 두 모델이 각각 실제 Android에서 클릭한 검수로 표현하지 않는다. Grok은 Cursor 경로만 사용했고 직접 xAI API는 쓰지 않았다.

초기 Claude는 표본에서 P1/P2 없음, Grok은 링크 동작 P2 한 건을 보고했다. Codex가 ELLE/ADP 반례를 보충하자 둘 모두 이를 실제 P2로 인정하고 결론을 수정했다. **두 모델의 최초 동의만으로 통과시키지 않았다.** Claude의 "목록 위치 상실 우려"는 실제 재현이 없고 왕복 테스트는 통과했으므로 별도 결함으로 채택하지 않았다. [최종 응답 발췌와 증거 판정](../../.nowhot-local/nh110/reviewer-excerpts.md).
