# NH109 알림·읽기 연속성 수리

2026-09-03 14:22 KST. David의 최종 지시는 기존에 수용한 기사 품질을 보존하면서 세 결함을 함께 수리하는 것으로 분류했다.
로컬 `http://127.0.0.1:4100/`에 적용했다. 라이브 수정·배포 완료 보고가 아니다.

Today의 기사 선별·국내외 비율·카테고리·출처·사진·요약 내용은 수정하거나 재생성하지 않았다.
새 프레임워크·패키지·분류 필터는 추가하지 않았다. 기존 브라우저 History/MessageChannel과 Node 파일 저장을 사용했다.
보관 대상은 기존 공개 발췌와 링크/메타데이터다. 원문 전체·사용자 정보·삭제된 자체 게시글을 복원하지 않는다.
기사가 내려가도 상세를 여는 목적이며, 보관 글을 현재 순위/선별 풀에 다시 넣지 않는다.

## 실제 상호 검수

- Codex: 전체 경로 추적·구현·테스트. 서브에이전트가 푸시, 화면 history, 기사 보관을 분리 담당했다.
- Claude: Orca의 기존 Claude Code 검수 세션(화면 라벨 Fable 5.1). 제품·알림·저장 수명 검수. 과도한 제목 유사도 필터는 추가하지 않기로 합의했다. 최종 제품 관점 이견 없음.
- Grok: Orca의 Cursor `Grok 4.6 Extra High`. 실제 diff에서 PC 번역 링크/상세 중첩 반례를 확인하고 수정을 검수했다. 최종 ACK·구페이지 noACK 실브라우저 결과를 확인해 한정 조건 해소에 동의했다.
- 독립 백엔드 검수: 과거 별칭의 제한 우회, 홈 앵커로 보관 글 재유입, SSR/RSS 링크 미보관, 의도적으로 지운 영문 발췌 복원을 발견해 공통 경계에서 수리했다.
- 테스트가 초록이어도 실제 SW 경로를 별도로 실행했다. 그 과정에서 실제 `navigate()` history 중첩을 발견했고, 현재/구페이지 둘 다 B→뒤로가기 목록→앞으로가기 B로 고쳤다.

두 모델의 합의는 해당 코드와 제시한 실행 증거에 대한 검수다. 실제 이용자 인터뷰나 Android 단말 인증으로 표현하지 않는다.
