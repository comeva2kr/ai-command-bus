# NowHot 공개 콘텐츠 검색 연결 — 2026-10-02

기존 하루 3회 오늘판 발행에 검색 페이지 생성을 연결했다. 별도 SEO 글을 만들지 않고, 서비스에서 이미 공개하는 제목·요약·본문·분석을 검색엔진이 읽을 수 있는 HTML과 고정 주소로 제공한다. 현재 상태는 **로컬 구현·검증 완료, 운영 배포 대기**다.

## 적용 내용

- 화제별 주소: `/today/YYYY-MM-DD/morning|lunch|evening/<화제 ID>`. 공개된 실제 내용, 출처, 개별 제목과 canonical을 첫 HTML에 포함한다.
- 날짜·판별 주소와 `/today` 보관 목록에서 14개 카테고리의 공개 화제로 이동한다. 새 판이 활성화되면 목록과 sitemap에 자동 반영한다. 같은 판을 정정해 빠진 이전 공개 화제도 주소와 발견 경로를 유지한다.
- 홈과 오늘판 제목에 일반 링크를 연결했다. 기존 상세창·공유·뒤로가기 동작을 유지한다.
- 공개 글 `/post/:id`, `/posts` 목록, `/posts?archive=1` 보관 목록을 연결했다. 과거 외부 공개 글도 기존 저장본을 통해 발견할 수 있다. 삭제된 자체 글과 차단된 출처는 상세·목록에서 제외한다.
- 기존 공개 목록의 `noindex`를 해제하고 sitemap과 메뉴에서 연결했다. 메뉴 변경은 서비스워커 캐시 버전에도 반영했다.

제공하는 본문은 실제 공개 데이터 범위다. 전문이 준비된 경우 전문을, 발췌만 공개한 경우 해당 발췌를 사용한다. 수집하지 않은 전문이나 분석을 만들어 넣지 않는다. 이 변경은 검색 가능 경로를 갖추는 것이며 모든 단어의 색인·순위·유입을 보장하지 않는다.

## 검수와 확인 근거

기준 운영 소스는 `27bb872`이며, 변경은 별도 작업 공간과 `codex/nowhot-search-pages` 브랜치에만 작성했다. 원래 개발 공간의 미완료 작업과 운영 데이터는 수정하지 않았다. 새 의존성·DB·별도 생성 작업은 추가하지 않았다.

- 코드 작성 전 공개 범위, 입력 검증, 비공개 필드, 이전 발행 증명 경계를 검토했다. 완료 전 Sol 6.1이 변경분과 실제 HTTP 검사를 독립 검수해 PASS를 반환했다.
- 날짜·판·ID 검증, 발행 기록 확인, HTML 및 JSON-LD escaping, 비공개 필드 제외, HTTP(S) 출처 제한, 삭제·차단 처리, 기존 제휴 고지와 sponsored 링크를 확인했다. 상세 조회를 위해 새 수집 작업을 실행하지 않는다.
- `npm test`: 총 2,144개 중 2,079개 통과, 실패 0개, 브라우저 런타임 미지정으로 65개 건너뜀.
- 번들 Playwright와 로컬 Chrome으로 브라우저 검사를 별도 실행: 72개 통과, 실패·건너뜀 0개. 위 65개와 중복되는 비브라우저 7개를 포함하므로, 합산 고유 검사 수는 2,144개다.
- 실제 HTTP 검사에서 첫 HTML의 화제 내용·canonical·일반 링크, 다음 발행 자동 반영, 정정 전 공개 화제 유지, 보관 글 발견, 비공개 필드와 삭제 글 제외, 잘못된 주소와 미발행 판 거부를 확인했다.
- `git diff --check` 통과. 검수한 `src`·`test` 변경분 SHA-256: `62bf233fc15420fd501e6a5fa4c1e5d430683d1f200f2c3c3186c96b99746da9`.

전체 검사에 필요한 기존 NH167 실험 자료는 격리 공간의 무시되는 `.nowhot-local` 아래로 복사했다. 원본을 변경하지 않았으며 커밋 대상에서 제외했다. 실행 로그는 `/tmp/nowhot-topic-search-final-20261002.log`, `/tmp/nowhot-topic-search-browser-final-20261002.log`다.

이번 최종 코드 검수 근거는 Sol 6.1이다. Orca 런타임이 꺼져 있어 Sonnet·Grok의 이번 변경분 검수 완료를 주장하지 않는다. 이전 전략 자문과 이번 코드 검수는 별개다.

## 운영 반영 후 확인

배포·push·검색 계정 변경은 수행하지 않았다. 배포 후 공개 URL의 HTTP 상태, 첫 HTML, canonical, sitemap, 이전 주소 유지 여부를 확인하고, Google Search Console·네이버 Search Advisor의 URL별 수집·색인 결과와 화제 검색어 노출·클릭을 측정한다. 현재 검색 유입 증가와 과거 노출 감소의 원인 확정 근거는 없다.

운영 반영은 WRC 운영 규칙 §9·§9A의 배포 승인 범위에 해당한다. 되돌릴 때는 이번 코드 변경을 취소하고 기준 `27bb872`로 배포한다. 발행 기록·공개 데이터·보관 파일 형식과 저장 데이터는 변경하지 않았으므로 데이터 이전이나 삭제는 필요 없다.
