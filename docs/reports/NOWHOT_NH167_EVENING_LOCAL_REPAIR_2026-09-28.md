# 지금핫 9월 28일 저녁판 로컬 개선 결과

**현재 상태: 로컬 수정과 교차 검수 완료. 공개 서비스에는 아직 반영되지 않았다.** 실제 9월 28일 원본 수집 풀·선정 패킷·분야 판정 자료가 이 작업 트리에 없어 같은 날 저녁판 전체를 재발행해 품질 수치를 확인하지는 못했다. 따라서 이 문서는 배포 승인서가 아니다.

검수한 9월 28일 공개 저녁판은 확인 가능한 4개 분야에 기사 54건이었다. 그중 **6건의 실제 기사 URL이 아침판에도 등장**했다. 현재 점심판과 저녁판 사이에는 동일 URL이 없었기에, 직전 판만 확인하던 방식이 원인이었다.

## 이용자 화면에서 달라지는 점

| 발견한 문제 | 이번 로컬 수정 |
| --- | --- |
| 아침에 본 기사가 점심에서 빠졌다가 저녁에 다시 등장 | 저녁판 후보를 고를 때 **같은 날 앞서 제공된 모든 판**의 실제 기사 URL을 대조한다. 관련기사로만 인용된 URL이나 새 후속 기사는 무조건 지우지 않는다. 이전 판 파일이 손상됐으면 중복을 허용하며 진행하지 않고 발행을 멈춘다. |
| 변화 기록이 없는데 `새 사건 0건`이라고 표시 | 실제 변화 건수가 있을 때만 숫자를 보여준다. 진짜 0건은 그대로 0건으로 표시한다. |
| 분야별 목록에 합본의 `288건` 요약이 따라옴 | 해당 합본 요약과 합본 변화 수치를 분야별 응답에서 제거했다. 이미 저장된 옛 판을 읽는 경로에도 적용된다. |
| 커뮤니티 태풍 GIF·국제정세/주가 게시글에 뉴스 후속 확인 문구가 붙음 | 커뮤니티 단독 글에는 뉴스 사건 프레임과 국제정세·증시 후속 문구를 붙이지 않는다. 실제 뉴스 기사에는 기존 안내를 유지한다. |
| 유족 글이 유머 선두에, 전시·성묘 골프 공분 글이 기술 분야에 배치 | 문제 되는 **그 분야 입장만** 취소한다. 함께 승인된 정상 분야는 유지한다. 그록의 반례에 따라 `미술관`과 `추모`라는 단어만으로 정상 기술·유머 글을 지우지 않게 좁혔다. |
| 엔비디아 주식의 받을 권리를 `빚`으로, SNL 패러디를 `치료`로 번역 | 기존 근거 해시·원제목 검수 경로로 아침 SNL 1건과 저녁 엔비디아 1건의 제목 및 기사 상세 발췌를 교정할 수 있게 했다. 검수 파일을 붙인 재생성은 제목과 상세 문장이 **둘 다** 반영되어야 기존 판을 재사용한다. 기존 공개판 자체는 바뀌지 않았다. |

## 세 사람의 역할과 반박

- **Claude Opus 5.5 Extra High**가 원인 추적, 주 수정, 실패→성공 테스트를 담당했다. 요청·실행 모델은 `claude-opus-5-5-xhigh`로 확인했다. 최종 독립 재검수에서는 구글뉴스 별칭 URL로 같은 기사가 다시 들어오는 경우와, `온라인 공분`이라는 말만으로 실제 기술 뉴스를 기술 분야에서 빼는 경우를 반박했다. 두 경우 모두 실패 테스트로 확인하고 고쳤다.
- **Cursor Grok 4.7 Extra High**가 수정본을 읽기 전용으로 공격했다. 요청 모델은 `grok-4.7-xhigh`, 작업 화면은 `Grok 4.7 Extra High`였다. 그록은 커뮤니티 국제정세 문구, `관련 근거`와 겹친 실제 기사 URL의 중복 누출, 넓은 분야 금지어라는 세 반례를 찾았다. 마지막 재검수에서 이 세 건과 오퍼스의 두 반례, SNL 발췌 길이 수정을 확인하고 **PASS-with-limits**로 판정했다. 그록은 전체 테스트를 직접 다시 돌리지는 않았다.
- **Codex**가 반례를 각각 실패 테스트로 재현한 뒤 최소 수정했고, 제목만 교정하면 상세 발췌에 오역이 남는 점과 아침 기사를 저녁 검수 파일에 넣으면 재생성이 실패하는 점을 추가로 바로잡았다. 교정한 SNL 발췌가 최소 길이 조건을 충족하지 못해 재생성을 막는 문제도 테스트로 찾아 수정했다. 아침·저녁 검수 파일은 분리하고 해시·원제목 일치 검사는 유지했다.

## 확인된 증거

- 변경 경로 집중 테스트: **140/140 통과**. 그록의 세 반례와 오퍼스의 두 반례는 수정 전 실패, 수정 뒤 통과했다. 제목·상세 발췌·최소 발췌 길이와 재사용 판정도 확인했다.
- 마지막 변경 뒤 다시 실행한 전체 테스트: **2,112건 중 2,036 통과, 12 실패, 64 건너뜀**. 실패한 12개 테스트 이름은 수정 전 실행과 같다. 11건은 이 작업 트리에 없는 과거 선택 실험 자료를 요구한다. 나머지 `baseline lock` 검사는 원래부터 다른 지문 불일치가 있었고, 이번 분야 분류 수정도 그 지문을 바꾸므로 녹색이라고 주장하지 않는다. 과거 기준 파일을 숫자 맞추기용으로 갱신하지 않았다.
- 공개 판 응답을 후보처럼 사용하는 **모의 재생**에서는 저녁 191개 중 직전 점심만 대조할 때 1개가 제외됐고, 아침+점심을 대조할 때 12개가 제외됐다. 추가 제외 11개는 아침에 이미 제공된 URL이다. 이 수치는 실제 수집 풀을 넣은 완성판 결과나 최종 분야별 기사 수가 아니다.
- `git diff --check` 통과. 로컬 코드에 새 의존성·외부 호출·비밀값 처리 변경 없음. 검수 파일은 운영자가 지정한 로컬 파일만 읽고, 빌더 인자는 셸을 거치지 않는다. 배포, push, 공개판 활성화, 광고·계정 변경은 하지 않았다.

## 아직 남은 확인과 출시 조건

1. **실제 9월 28일 빌드 자료로 전체 판 재생성 미검증.** 현재 작업 트리에는 해당 날짜의 원본 풀·선정 패킷·분야 판정 입력이 없다. 따라서 14개 분야의 최신 기사 비율, 부족 개수, 다양성, 중요도와 제목 품질을 완성판으로 측정할 수 없다.
2. **서로 다른 URL의 같은 사건**은 이번 정확 URL 중복 방지 대상이 아니다. 새 사실이 있는 후속 기사와 단순 재탕을 구별하는 사건 단위 검사는 별도 작업이다. 저녁판의 오래된 인기글 채움과 남아 있는 다른 분야 오배치도 실제 입력으로 다시 봐야 한다.
3. **번역 교정은 해당 두 근거에 한정된다.** 새 근거 해시로 재수집되거나 같은 종류의 새 오역이 오면 자동으로 고쳐지는 일반 번역 품질 게이트는 아직 없다. 검수 파일도 자동 정시 발행에 연결하지 않았고, 해당 슬롯의 원본 입력과 함께 운영자가 명시적으로 지정해야 한다.
4. **추가 경계 사례가 남아 있다.** 유머 분야 금지어 `숨진·숨져`는 `숨진 척하는 고양이` 같은 가상 사례도 걸러낼 수 있다. 검수 파일의 원제목과 독자 제목은 재생성 시 확인하지만 이미 활성화된 판을 재사용하는 빠른 검사에서는 각각 다시 대조하지 않는다. 이번 두 교정은 실제 저장된 값과 일치했다.
5. **공개 서비스·휴대전화 동작 미검증.** 이 작업은 로컬 코드와 공개 응답의 읽기 전용 대조까지다. 출시 전 같은 입력의 오프라인 전체 재생성, 실제 화면·링크 확인, 그 결과에 대한 최종 독립 검수가 필요하다.

**판정: 로컬 결함 수정은 완료, 운영 배포는 HOLD.** 실제 전체 재생성 결과와 공개 화면을 확인하기 전에는 “저녁판 품질 문제가 모두 해결됐다”거나 “라이브에 반영됐다”고 알리지 않는다.
