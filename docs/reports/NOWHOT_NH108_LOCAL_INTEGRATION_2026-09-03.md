## 실제로 바뀐 것

1. **원문 미확인 안내:** 실제 인증 필요/접근 거부/본문 부족과 후처리 실패를 구분한다.
   전체 본문을 못 읽어도 이미 같은 기사 피드에서 확인한 200자 이하 발췌·사진은 잃지 않는다.
   접근을 못 한 본문을 읽었다고 하거나 추정 요약을 채우지 않는다.
2. **편성:** 뉴스 국내 50~70%, 경제 50~60%, 기술 50~70%, 정치 80~90%는 소프트 가이드다.
   실제 발행 14건을 대상으로 기존 적격성·출처 한도·우선순위를 보존하고 상대 중요도 차이
   10% 이내에서만 조정한다. 해외 추가 승격은 기존 시장 파급 또는 독립 교차보도가 있어야 한다.
   대형 매체라는 이유만으로 해외 지역 소식을 끌어올리던 초안은 3자 반례 검수로 제거했다.
   자연스럽게 상위에 오른 해외 보도는 이 추가 승격 조건으로 탈락시키지 않는다.
3. **번역:** PC는 원문을 열고 브라우저 번역을 선택하는 방식, 모바일은 기존 네이버 앱 연결이다.
   버튼을 누르자마자 자동 번역되는 기능이라고 표현하지 않는다. 네이버 앱 실제 실행은 미검증이다.
4. **커뮤니티:** 준비된 출처 정본의 사진·발췌를 상세에서 사용한다. 확보하지 못한 Ppomppu 본문·
   사진을 새로 만들거나 클릭 시 가져오지 않는다. 접근 거부 사례 자체는 남는다.
5. **국내 패션:** ELLE 공식 공개 RSS 15개 중 FASHION 4건을 기존 수집기에 연결했다.
   해당 태그가 없거나 다른 섹션이면 통과하지 않는다. 쇼핑몰 카탈로그나 광고로 채우지 않았다.

통합 중 현재 자동 점심판부터 존재한 Broadcom/HPE 오병합을 추가로 발견했다.
일반 단어 `earnings`와 `upbeat/beat`만으로 같은 회사 보도라고 판단한 기존 burst 예외가 원인이었다.
기존 일반 단어 목록에 `beat` 하나만 추가해 두 회사의 기사·제목·출처를 분리했다.
회사명 하드코딩이나 새 군집 알고리즘은 없으며 같은 회사 실적 보도의 정상 병합은 유지한다.
