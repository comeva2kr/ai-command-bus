# NH167 라이브 직전 적대 검수 — 2026-09-30

## 결론: 현재 후보 그대로의 배포는 보류

최신 기사 우선 편성과 기존 화면 기능은 개선됐지만, **기사를 14개보다 늘리는 구간에서 같은 사건을 세 번 싣는 실제 반례**가 발견됐다. 기존 자동 검사도 이 판을 통과시킨다. 앞선 ‘로컬 검사 완료’를 ‘독자 품질까지 배포 가능’으로 해석하면 안 된다.

이번 작업은 읽기 전용 검수다. 제품 수정·커밋·push·배포·판본 활성화·실제 푸시 발송은 하지 않았다. 보고서와 인계 기록만 갱신한다.

### 중복의 원인

기존 사건 묶음이 `1천60만대`, `1060만대`, `1000만 고지`처럼 표현이 다른 같은 소식을 갈라 놓았다. 예전 14개 상한에서는 뒤의 두 건이 잘렸지만, 이번 추가 기사 경로는 **이미 선택된 기사와 같은 사건인지 재확인하지 않아** 세 건 모두 노출한다.

- 위치: `tools/build-slot-canonical-edition.mjs:120–142`, `src/feed/slot-canonical-edition.js:170–175`.
- 재현: 후보의 `lanes.auto`에서 1·16·17번째 ID를 `issueTable[id].reader.headline`로 읽는다. `validateSlotCanonicalEdition`은 이 판에 `ok: true`를 반환한다.
- 제목만 다를 뿐, 세 출처 모두 투싼 출시 22년 누적 판매라는 같은 발표다. 새로운 후속 사실로 세 자리를 정당화할 근거는 확인되지 않았다.
- **채택하지 않을 수정:** 숫자가 비슷하면 무조건 같은 사건으로 합치기, 몇 단어가 겹치면 무조건 삭제하기. `1천60만=1060만`처럼 정확히 같은 수의 표기는 정규화할 수 있지만, `1000만≈1060만`을 일반 규칙으로 적용하면 실제 변화까지 지워진다. 원자료와 사건 맥락에 근거해야 한다.
- 분야 첫 번째 값만 허용하거나 외국어 원문을 일괄 차단하는 우회도 채택하지 않는다. 기존 복수 분야·외신 가치를 유지하는 것이 조건이다.

## 2. 개선은 확인됐지만 범위를 제한해야 하는 부분

| 항목 | 현재 확인된 상태 |
|---|---|
| 최신성 | 같은 실제 풀의 로컬 재생에서 저녁 뉴스의 점심 이후 비중 91.7%, 점심 뉴스의 07시 이후 비중 86.0%. 두 판의 뉴스 대표 기사에 전날 날짜 0건. 모든 미래 판에 대한 보장은 아니다. |
| 아침·점심·저녁 사이 반복 | 두 재생판에서 이전 판과 반복되는 5건·6건을 제외했다. 추가 사실이 있는 후속 기사도 보존했다. 위의 ‘한 판 안에서 같은 사건 세 번’은 별개의 미해결 문제다. |
| 기사 수 | 적격 기사 8개 목표, 기본 14개, 조건을 통과한 추가 기사로 최대 20개. 숫자를 채우기 위한 무조건 보충은 하지 않는다. 현재 추가 구간의 품질 결함 때문에 배포 보류다. |
| 제목 정정 지속성 | 발행 전에 존재한 검토 파일의 엔비디아·보스 정정은 재생판 제목·본문에 반영되고 캐시 재사용으로 되돌아가지 않았다. **이미 발행된 뒤 추가한 정정 파일은 정시 작업이 자동 재적용하지 않는다.** 해당 슬롯은 `already_active`로 끝나므로 별도 정정 실행이 필요하다. |
| 본문 확보 | 앞선 재생판의 본문 확보 실패 33건·34건은 남아 있다. 모든 기사 전문 확보 완료로 표현하지 않는다. |
| 유입 분석 | 그록 독립 검사와 Codex 재현에서 측정 시작 전 구간·저장 기록이 사라진 구간은 `unmeasured`, 수치는 `null`이다. 0명으로 꾸미지 않는다. 측정 전부터 이어진 세션은 새 세션으로 소급 집계하지 않으며, 30분 이상 쉰 뒤 새로 시작한 측정 세션은 1건 집계했다. 새 결함은 확인되지 않았다. |
| 실기기 | 실제 갤럭시·아이폰 푸시 도착과 OS 뒤로가기는 이번 검수에서 시험하지 않았다. 로컬 Chrome 검사와 구분한다. |

발행 후 정정까지 자동화됐다는 설명은 정정한다. `tools/run-slot-canonical-prepublish.mjs:379–390`은 활성 판을 먼저 반환한다. 개선 시에는 정정 근거가 달라진 판만 다시 준비하고, 기존 공유 판본과 알림 중복 방지 기록을 보존해야 한다.

추가로 그록은 함수 수준에서 `$99`와 `$99.00`을 서로 다른 새 가격으로 판정하는 반례를 찾았고 Codex가 재현했다. 실제 가격 변화가 아닌데 반복을 남길 수 있다. 현재 후보 화면에서 그 가격 사례가 실제 중복된 것은 확인하지 않았다. 동일한 수의 표기 정규화를 보강할 때 함께 고치되, `$99`→`129달러` 같은 진짜 가격 변화는 유지해야 한다.

## 3. 실제 검증 결과

- 현재 운영 저장소 HEAD와 실행 중 컨테이너의 대조 대상 22개 파일은 후보 기준 커밋 `cf13d28b7dcd370e1eda88988cd5b5cf587425e0`와 일치했다. 현재 후보 변경이 라이브에 들어간 것은 아니다.
- 제품·검사 파일 33개의 해시는 앞선 완료 기록과 일치한다. 이번 검수 도중 제품 변경은 없다.
- 전체 검사 2,131개 중 2,066개 통과, 브라우저 실행 환경 때문에 65개 건너뜀. 기존 설치된 Chrome·Playwright로 관련 72개를 다시 실행해 모두 통과했다. 건너뛴 65개를 전부 대조했으므로 **중복을 뺀 2,131개 모두 이번에 통과**했다.
- 배포 이미지와 같은 복사 대상만 모은 임시 패키지를 Node 22에서 구동했다. 두 후보 오늘판 API 200, 정확한 판 ID와 기사 수 일치, 임의 대체판 없음, 관리자 미인증 요청 401을 확인했다.
- 실제 Linux Docker 이미지 빌드는 로컬 Docker가 없어 수행하지 않았다. 위 패키지 구동을 Docker 빌드 성공으로 표현하지 않는다.
- `git diff --check` 통과. 테스트 통과와 실제 독자 품질을 구분한다. 이번 중복 사례가 그 차이를 보여준다.

## 4. 세 검수자의 의견과 판정

- **Codex:** 운영 코드·실행 파일과 후보 기준을 대조하고, 전체·브라우저 검사 및 배포 패키지 구동을 담당했다. 투싼 1→3건과 추가 구간 오분류·번역투를 실제 판본에서 독립 확인했다.
- **Claude Fable 5.1 high:** 편집·날짜·반복·교정·구버전 호환성을 검수했다. ‘같은 사건 세 번’을 배포 차단으로 판정했다. 숫자 유사 허용·첫 분야만 사용·외신 일괄 제외 제안은 위 부작용 때문에 그대로 채택하지 않는다.
- **Cursor Grok 4.7 Extra High:** 유입 분석과 경계 조건을 독립 검수한 뒤, 투싼 세 기사가 별개의 새 사실인지 반박 검토했다. 동아일보 요약의 `1061만6102대`까지 대조해 같은 누적 판매 발표로 판정했고, 배포 불가에 동의했다. 유입 분석 집중 검사 7개 통과·브라우저 1개 건너뜀; Root의 별도 브라우저 실행으로 해당 검사는 통과했다. 숫자 표기 반례도 Codex가 재현했다.

구버전이 새 자료 형식을 거부하는 것은 그 자체로 버그가 아니라는 그록의 반론은 수용한다. 따라서 ‘새 결함’ 대신 **배포·복구 선행조건**으로 분류했다. 다만 예전 이미지와 포인터만 복원하자는 두 검수자의 제안은 새 공유 링크와 유입 기록 보존을 충분히 다루지 못한다. 이 부분은 별도 복구 실증이 있어야 완료다.

모델 기록: Fable은 요청·실행 설정 `claude-fable-5-1 / high`; Grok은 Cursor 가용 목록의 `grok-4.7-xhigh`, 실행 화면 `Grok 4.7 256K Extra High`를 확인했다. 제공자 내부에서 별도 확정한 응답 영수증까지 확보했다는 뜻은 아니다.

Orca 실행 `run_d178a3da7d2d`: Fable `ctx_14834bfab56d`, Grok `ctx_79603a4366c3`. 두 `worker_done`과 실제 결과물을 회수·검토하고 완료 메시지 ACK 및 해당 워커 자원 해제를 마쳤다. 이번 검수 워커 두 개 모두 `released`, 반환 대기 자원 0. 기존 실행의 다른 이력·보존 자원은 변경하지 않았다.
