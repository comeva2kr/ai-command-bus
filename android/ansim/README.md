# 안심스캔 안드로이드 앱

한 앱에서 오프라인과 온라인을 같이 쓴다.

- **매장(오프라인)**: 앱을 열면 스캐너 — 바코드 스캔, 라벨 사진, 판정·대체품 (서버의 PWA를 WebView로)
- **쇼핑앱(온라인)**: 백그라운드 접근성 서비스가 지금 화면의 쇼핑몰 앱을 알아보고,
  상품 화면이면 오른쪽 가장자리에 **점수 탭**을 띄운다. 누르면 이유와 같은 몰의 대체품.
  - 쇼핑몰 앱: 쿠팡, 네이버(스마트스토어), 컬리, SSG, 11번가 — 패키지 이름으로 인식
  - 브라우저: 크롬, 삼성 인터넷 — 주소창 호스트로 인식 (모바일 브라우저는 웹 확장을 못 써서 이 길로 덮는다)
  - 대체품 버튼은 같은 몰 링크 → 그 몰 앱이 깔려 있으면 앱 링크로 앱이 열린다

## 구조 (외부 라이브러리 없음, 화면도 코드로)

| 파일 | 하는 일 |
|---|---|
| `MallWatcherService.kt` | 접근성 서비스. 몰 앱 인식 → 화면 글자 수집 → 서버 판정 → 탭 갱신. 다른 앱은 패키지 이름만 보고 탭을 숨긴다 |
| `FloatingTab.kt` | 오른쪽 가장자리 탭(위아래 끌기, 위치 기억) + 상세 패널(바깥 누르면 닫힘). `TYPE_ACCESSIBILITY_OVERLAY`라 '다른 앱 위에 그리기' 권한 불필요 |
| `ScreenReader.kt` | 화면 글자 줄 → 상품명 + 고시표 키-값 (순수 코드, 단위 테스트) |
| `Malls.kt` | 패키지·주소창 → 몰 (몰 id는 웹 코어와 같음, Node 테스트가 확인) |
| `AnsimApi.kt` | `POST /api/ansim/analyze` — 판정은 서버 코어가 한다(웹·확장·앱 같은 점수) |
| `MainActivity.kt` | 스캐너 WebView + 탭 켜기(고지 후 접근성 설정으로). `window.AnsimNative`로 아이 정보를 탭과 공유 |
| `Store.kt` | 아이 정보·서버 주소·탭 위치 (기기 안) |

고시표가 접혀 있어 원재료가 안 보이면 상품명만 서버로 간다. 서버는 웹 확장이나 다른
사용자가 같은 상품 페이지에서 읽어 둔 원재료로 판정한다(`src/ansim/server.js`의 listing 기억).

## 빌드·실행

```bash
# 안드로이드 스튜디오에서 android/ansim 열기 → Run (에뮬레이터)
# PC에서 서버: npm run ansim   (에뮬레이터는 http://10.0.2.2:4100 으로 붙는다)
```

앱 첫 화면 위쪽 버튼으로 접근성 서비스를 켠다. 버튼을 길게 누르면 서버 주소를 바꿀 수 있다.
실기기·실서비스는 HTTPS 서버가 필요하다(WebView 카메라는 보안 출처에서만 열린다).

## 확인한 것 / 못 한 것

이 저장소의 개발 환경에서는 안드로이드 SDK를 받을 수 없어 APK를 만들지 못했다. 대신:

- 앱의 코틀린 소스 전부를 Android 15 프레임워크 jar(Robolectric android-all)에 대고 컴파일 — 통과
- JVM 단위 테스트 10개(화면 읽기, 몰 인식, 서버 실제 응답 파싱) — 통과
- Node 테스트(`test/ansim-android-contract.test.js`)가 서버 응답이 앱 픽스처와 같은 모양인지 CI에서 확인

실기기에서 꼭 볼 것:

- [ ] 몰 앱 패키지 이름(`Malls.kt`) — 특히 컬리·SSG·11번가
- [ ] 쿠팡 앱 상품 화면의 접근성 트리에 상품명·필수 표기정보 글자가 나오는지(웹뷰 영역 포함)
- [ ] 몰별 상품명 view id를 찾아 `ScreenReader.TITLE_VIEW_IDS` 채우기 (지금은 경험칙)
- [ ] 크롬·삼성 인터넷 주소창 view id
- [ ] 탭·패널이 몰 앱의 구매 버튼과 겹치지 않는지, 배터리 영향

## 구글 플레이 정책 — 출시 전 가장 큰 관문

접근성 API를 장애인 보조가 아닌 목적으로 쓰는 앱은 구글 플레이 심사에서 엄격히 본다
(앱 안 명확한 고지·동의, 데이터 사용 신고, 심사 시 사용 목적 설명). 이 앱은 고지 화면
(`MainActivity.explainAndOpenAccessibility`)을 넣었지만 승인을 보장하지 않는다.
거절되면 대안:

1. **공유 버튼**: 쿠팡 앱 상품 화면 → 공유 → 안심스캔 (상품 링크를 받아 판정). 정책 문제 없음, 대신 한 번 더 누름
2. **화면 캡처 분석**: 탭을 누르면 그 순간 화면을 캡처(MediaProjection)해 글자를 읽기. 매번 사용자 승인 필요
3. 플레이 밖 배포(APK 직접 배포) — 일반 사용자 대상으론 비추천
